# Roadmap

## Phase 1: Registry

- Define records for every external capability.
- Store name, description, input contract, output contract, owner, and level.
- Add sample connectors for files, database reading, GitHub reading, and email draft creation.

## Phase 2: Validation

- Validate inputs before execution.
- Return clear error messages.
- Add tests for invalid input.

## Phase 3: Access control

- Check user, project, and agent permissions.
- Record allowed and denied requests.
- Add audit records.

## Phase 4: Review flow

- Add preview mode.
- Add human review for sensitive actions.
- Add execution records.

## Phase 5: Interview package

- Add architecture notes.
- Add security notes.
- Add interview notes.
